## API Restful

API demo para la demostracion de funcionalidades, opciones, ventajas y beneficios que puede aportar el uso de una API en laravel para el sistema SMProg/SOT

## Endpoints

### Endpoints de Autenticacion

- `/api/v1/sot/login`
- `/api/v1/sot/logout`

### Endpoints de SOT

- `api/v1/sot/obtener_agrupaciones`
